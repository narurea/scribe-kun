# 文字起こしMacアプリ 仕様書

元の仕様書: https://claude.ai/artifact/8irPYn2vmshjfNfjxzfVmS （2026-10-26 時点の内容を転記）

## 1. 概要

動画ファイルをウィンドウに入れると、Mac上だけで文字起こししてテキストファイルを書き出すネイティブアプリを作る。音声はネットに送らず、すべてローカルで処理する。

| 項目 | 内容 |
| --- | --- |
| アプリ名 | 未定（仮：Transcribe） |
| 対象環境 | macOS 14 Sonoma 以降、Apple Silicon（M1以降） |
| 開発環境 | M4 Mac（ユニファイドメモリ24GB）、Xcode |
| 実装 | Swift / SwiftUI ＋ whisper.cpp |
| 管理 | Git（将来的にGitHubで公開） |
| 目標速度 | 1時間の動画を10分以内（large-v3-turbo使用時） |

## 2. 機能要件

### 2.1 入力

- ウィンドウへのドラッグ&ドロップでファイルを追加できる
- 「ファイルを選択」ボタンからも追加できる（複数選択可）
- 対応形式（v1）：mp4、mov、m4v、および音声ファイル（m4a、mp3、wav）
- 複数ファイルはキューに入り、上から順に1本ずつ処理する
- 非対応形式は追加時にエラー表示し、キューに入れない

### 2.2 文字起こし

- 動画から音声を取り出し、16kHzモノラルに変換してwhisper.cppに渡す
- 言語は自動判定（判定結果を画面に表示する）
- 処理中は進捗（%）と経過時間を表示し、キャンセルできる

### 2.3 出力

出力形式は設定で切り替える。複数同時に選べる。

| 形式 | 拡張子 | 中身 |
| --- | --- | --- |
| 本文のみ | .txt | 区切りごとに改行したテキスト |
| タイムスタンプ付き | .txt | 各行の頭に [00:12:34] を付けたテキスト |
| 字幕 | .srt | 開始・終了時刻付きの字幕形式 |

- ファイル名は「元の動画名.txt」「元の動画名.srt」（タイムスタンプ付きtxtは「元の動画名_timestamps.txt」）
- 保存先は設定で決めたフォルダに固定する
- 同名ファイルがある場合は「_2」などの連番を付けて上書きしない
- 完了したらFinderで表示ボタンと通知を出す

### 2.4 設定

- 出力形式（チェックボックスで複数選択）
- 保存先フォルダ（未設定時は「書類/Transcripts」）
- 使用モデル（turbo / large-v3 / small）
- 言語：基本は自動判定、必要なら手動で固定できる上書きオプション

## 3. 画面仕様

画面はメインウィンドウと設定画面（⌘,）の2つだけにする。

### 3.1 メインウィンドウ

- 上部：ドロップエリア（「ここに動画をドロップ」＋「ファイルを選択」ボタン）
- 中央：キュー一覧。1行ごとにファイル名、状態（待機中／処理中 ○%／完了／エラー）、判定言語を表示
- 各行の操作：処理中はキャンセル、完了後は「Finderで表示」
- 下部：保存先フォルダのパスと、設定を開くボタン
- 初回起動時はモデル未ダウンロードなので、ダウンロード案内と進捗を表示する

### 3.2 設定画面

| 項目 | UI | 初期値 |
| --- | --- | --- |
| 出力形式 | チェックボックス×3 | 本文のみ |
| 保存先フォルダ | パス表示＋「変更…」ボタン | 書類/Transcripts |
| モデル | ポップアップメニュー | large-v3-turbo |
| 言語 | ポップアップメニュー（自動／日本語／英語…） | 自動 |
| 完了通知 | トグル | オン |

## 4. 技術構成

外部コマンドに頼らず、アプリ単体で動く構成にする。GitHubで配るときに「別途ffmpegを入れてください」が不要になるため。

### 4.1 処理の流れ

1. ファイルを受け取り、AVFoundationで形式をチェック
2. AVFoundation（AVAssetReader）で音声トラックを取り出し、16kHz・モノラル・Float32に変換
3. whisper.cppに渡して文字起こし（Metalで GPU処理）。進捗はコールバックで受け取る
4. 区切り（セグメント）ごとの開始・終了時刻とテキストを受け取る
5. 設定に応じて txt／タイムスタンプ付きtxt／srt に整形して保存

### 4.2 使う技術

| 役割 | 技術 | 理由 |
| --- | --- | --- |
| UI | SwiftUI | Macネイティブで見た目が自然、コード量が少ない |
| 音声抽出 | AVFoundation | macOS標準。ffmpeg不要でライセンス問題もない |
| 文字起こし | whisper.cpp（Swift Package） | Apple SiliconのMetal対応で速い。MITライセンス |
| 設定保存 | UserDefaults（@AppStorage） | 設定項目が少ないので十分 |
| 保存先の権限 | Security-scoped bookmark | サンドボックス下で設定フォルダに書き込み続けるため |

### 4.3 モデル管理

- モデルはアプリに同梱せず、初回起動時にHugging Faceからダウンロードする（turboで約1.6GB）
- 保存場所：~/Library/Application Support/<アプリ名>/models/
- 設定でモデルを切り替えたとき、未ダウンロードならその場で取得する
- 補足：AVFoundationはmkvやwebmを読めない。対応が必要になったらv2以降で検討する

## 5. Git管理とGitHub公開

最初からGitで管理し、そのまま公開できる状態を保つ。モデルファイルなど大きいものは絶対にコミットしない。

### 5.1 リポジトリ構成

```
transcribe-mac/
├── README.md          # 使い方・スクショ・ビルド方法
├── LICENSE
├── .gitignore
├── docs/
│   └── SPEC.md        # この仕様書
├── Transcribe.xcodeproj
└── Transcribe/
    ├── App/           # エントリポイント
    ├── Views/         # メイン画面・設定画面
    ├── Services/      # 音声抽出・文字起こし・モデル管理
    ├── Formatters/    # txt / srt 書き出し
    └── Resources/
```

### 5.2 運用ルール

- ブランチ：main は常に動く状態。作業は feature/xxx で切ってマージする
- コミットメッセージ：feat: / fix: / docs: などの接頭辞を付ける（Conventional Commits）
- バージョン：v0.1.0 からタグを打つ。最初の公開版を v1.0.0 にする
- .gitignore：xcuserdata、DerivedData、.DS_Store、*.bin（モデル）を除外
- whisper.cpp は Swift Package Manager で参照し、ソースを直接コピーしない

### 5.3 公開時の注意

- ライセンスを決めて LICENSE を置く（whisper.cpp がMITなので、MITが一番シンプル）
- 配布用の.appは GitHub Releases に置く
- Apple Developer Program（年$99）に入らないと公証（notarization）できず、ダウンロードした人に「開発元を確認できない」警告が出る。入らない場合はREADMEに開き方を書くか、ソースからビルドしてもらう形にする

## 6. 非機能要件・開発ステップ・未決事項

### 6.1 非機能要件

- 音声・動画・文字起こし結果を外部に送信しない（モデルのダウンロードのみ通信する）
- 処理中もUIが固まらない（文字起こしはバックグラウンドで実行）
- 長い動画（2時間程度）でもメモリ不足で落ちない
- App Sandbox を有効にする

### 6.2 開発ステップ

- [ ] Xcodeプロジェクト作成、git init、.gitignore と README の雛形をコミット
- [ ] whisper.cpp を組み込み、固定の音声ファイルで文字起こしできることを確認
- [ ] AVFoundationで動画から音声を取り出す処理を作る
- [ ] メイン画面（ドロップ／ファイル選択／キュー表示）を作る
- [ ] txt・タイムスタンプ付きtxt・srt の書き出しを作る
- [ ] 設定画面と保存先フォルダの権限処理を作る
- [ ] モデルの初回ダウンロード、進捗表示、キャンセル、通知を作る
- [ ] 実際の動画で速度と精度を測る
- [ ] ライセンス・README・スクショを整えて v1.0.0 をGitHubに公開

### 6.3 未決事項
